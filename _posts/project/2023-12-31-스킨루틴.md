## 개요
> 피부 유형 설문과 날씨 정보를 바탕으로 사용자에게 맞는 피부 관리 루틴을 제공하는 앱입니다.  
> Android 개발자로 참여했지만 iOS 출시가 필요해지면서 Flutter를 학습해 Android와 iOS 모바일 앱을 개발했습니다.

- 기간: 2023. 07. 01. ~ 2023. 12. 31.
- 협업: 기획·디자인·백엔드·인공지능 담당자
- 기술: `Dart` · `Flutter` · `Cubit` · `ObjectBox` · `ARCore` · `ARKit` · `Jenkins`
- 역할: Android·iOS 모바일 앱 개발

## 주요 작업

### Android Native PoC와 Flutter 전환

- Android Native로 AR 얼굴 추적과 자동 촬영 기능의 구현 가능성을 확인하는 PoC를 진행했습니다.
- Android와 iOS 동시 출시가 필요해지면서 Flutter를 학습해 두 플랫폼의 앱을 개발하고 출시했습니다.

### 피부 유형과 날씨를 반영한 루틴 생성

- 설문 답변을 항목별로 점수화해 네 축의 조합으로 피부 유형을 분류했습니다.
- OpenWeatherMap의 `One Call API 3.0`과 `Air Pollution API`에서 습도·자외선·미세먼지 정보를 조회하고, 피부 유형과 최근 받은 시술을 함께 반영해 날짜별 피부 관리 루틴을 생성했습니다.
- 루틴 생성과 알림을 앱 내부에서 처리하고, 루틴과 수행 기록은 ObjectBox에 저장했습니다.

### AR 기반 얼굴 자동 촬영

- 얼굴 필터와 효과를 덧붙일 수 있어 AR을 선택했고, Android에서는 ARCore, iOS에서는 ARKit을 활용해 얼굴 추적 기능을 구현했습니다.
- 얼굴의 회전값을 쿼터니언으로 구한 뒤 [오일러 각으로 변환](https://www.euclideanspace.com/maths/geometry/rotations/conversions/quaternionToEuler/){:target="_blank"}해 방향과 기울기를 계산했습니다.
- 얼굴과 카메라의 3차원 좌표로 [유클리드 거리](https://en.wikipedia.org/wiki/Euclidean_distance){:target="_blank"}를 계산해 자동 촬영에 적절한 거리인지 판단했습니다.
- 얼굴이 화면 중앙에서 정면을 향하고 거리와 밝기가 기준을 충족할 때 자동 촬영되도록 구현했습니다.

### 배포와 출시

- Dockerfile과 uWSGI 설정을 작성해 Django 백엔드의 실행 환경을 구성했습니다.
- GitHub Webhook과 Jenkins를 구성해 저장소에 변경사항이 push될 때 백엔드가 자동으로 배포되도록 했습니다.
- 팀원들이 실제 기기에 설치해 테스트할 수 있도록 Android APK와 Ad Hoc 방식으로 내보낸 iOS IPA를 Firebase App Distribution으로 공유했습니다.
- Flutter 앱을 Android와 iOS에 유료로 출시했으며, 현재는 스토어에 게시되어 있지 않습니다.

## 회고

Android와 iOS 앱은 출시했지만, 피부 분석 기능은 최종 연동까지 마무리하지 못했습니다.<br>
AI 모델을 서버에 배포하는 방법을 찾아봤지만 실제 연동까지 이어가지는 못했고, 최종 버전은 별도의 백엔드 서버 없이 서비스 로직을 앱 내부에서 처리하는 형태로 출시했습니다. 사용 통계는 Firebase Analytics로 수집했습니다.

돌아보면 당시 백엔드와 배포 인프라에 대한 이해가 더 있었다면, 피부 분석 기능을 서비스에 연결할 방법도 더 구체적으로 검토할 수 있었을 것 같습니다. 이 경험을 계기로 이후 Java·Spring 백엔드와 인프라를 공부하게 됐습니다.
